# Проекты

## Описание
Модуль проектов позволяет пользователям создавать и управлять проектами.

## Статусы проекта
- `PENDING` - На модерации (для проектов, созданных студентами)
- `APPROVED` - Одобрен (автоматически для Админов и Сотрудников вуза)
- `REJECTED` - Отклонен

## История изменений
Любое обновление проекта сохраняется в истории (`project_history`), фиксируя кто и что изменил.

## API Эндпоинты

### Создание проекта
`POST /projects`
*Требуется авторизация*

Тело запроса:
```json
{
  "title": "Название проекта",
  "description": "Описание проекта",
  "links": [
    {
      "url": "https://github.com/user/repo-front",
      "description": "Frontend"
    },
    {
      "url": "https://github.com/user/repo-back",
      "description": "Backend"
    }
  ]
}
```

### Получение всех проектов
`GET /projects`

Возвращает список проектов со связанными ссылками, автором и историей изменений.

### Получение одного проекта
`GET /projects/:id`

### Обновление проекта
`PATCH /projects/:id`
*Требуется авторизация*

Тело запроса (все поля опциональны):
```json
{
  "title": "Новое название",
  "description": "Новое описание",
  "status": "APPROVED",
  "links": [...]
}
```
При обновлении создается запись в истории.

### Удаление проекта
`DELETE /projects/:id`
*Требуется авторизация*

### Приглашение в проект
`POST /projects/:id/invitation`
*Требуется авторизация (только автор)*

Возвращает токен приглашения:
```json
{
  "token": "uuid-token"
}
```

### Присоединение к проекту
`POST /projects/join/:token`
*Требуется авторизация*

Позволяет пользователю присоединиться к проекту по токену приглашения.
