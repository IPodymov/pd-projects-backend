# Учебные заведения и Группы

## Описание
Модуль для управления учебными заведениями (Вузы, Школы) и учебными группами/классами.

## Типы заведений
- `UNIVERSITY` - Вуз
- `SCHOOL` - Школа

## API Эндпоинты

### Учебные заведения

#### Создание заведения
`POST /institutions`
*Требуется авторизация*

Тело запроса:
```json
{
  "name": "МГТУ им. Н.Э. Баумана",
  "type": "UNIVERSITY"
}
```

#### Получение всех заведений
`GET /institutions`

#### Получение одного заведения
`GET /institutions/:id`

#### Обновление заведения
`PATCH /institutions/:id`
*Требуется авторизация*

#### Удаление заведения
`DELETE /institutions/:id`
*Требуется авторизация*

### Учебные группы

#### Создание группы
`POST /student-groups`
*Требуется авторизация*

Тело запроса:
```json
{
  "name": "ИУ5-11Б",
  "institutionId": 1
}
```

#### Получение всех групп
`GET /student-groups`

#### Получение одной группы
`GET /student-groups/:id`

#### Обновление группы
`PATCH /student-groups/:id`
*Требуется авторизация*

#### Удаление группы
`DELETE /student-groups/:id`
*Требуется авторизация*
